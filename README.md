# travel-landing-page
A simple and visually appealing travel landing page designed to showcase beautiful destinations and inspire people to explore the world.

Project Overview

This project is a static travel website built using HTML and CSS. It features a travel-themed hero section, popular destination cards, and a call-to-action section.

The goal of this project is to practice frontend development fundamentals, including layout design, Flexbox, CSS Grid, background images, and styling.

Features

- Navigation bar with Home, About, Destinations, and Contact links.
- Hero section with a scenic background image.
- Popular destinations section featuring Paris, Santorini, and Bali.
- Destination cards with images and descriptions.
- Call-to-action section.
- Styled footer.

Technologies Used

- HTML5
- CSS3
  - Flexbox
  - CSS Grid
  - Background Images
  - Object-fit
  - Basic styling and layout properties

How to Run Locally

1. Clone this repository:
   
   git clone git@github.com:sakshi03-git/travel-landing-page.git

2. Open the project folder in VS Code.

3. Open "index.html" in your browser or use the Live Server extension.
